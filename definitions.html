What to define

Quotient dimension-graded cycles by rational equivalence, with proper pushforward, flat pullback, regular-immersion refined Gysin maps, Chern operators and their relations. Start with finite-type schemes over a field. Extend to the stated quotient-stratified algebraic stacks and rational proper-support Chow groups, retaining stabilizer denominators; compare degree and cycle-class operations only within their coefficient and smoothness hypotheses.

What to define

For a flat finitely presented group algebraic space G over S, define the groupoid of right G-torsors on the fppf site, locally equivariantly isomorphic to G. For arbitrary flat affine G use fpqc torsors without imposing finite presentation; compare this with the fppf formulation when G is finitely presented. Construct contracted products, associated bundles, inner forms and the pointed set of isomorphism classes H¹(S,G), without choosing a global point.

Sample API

A formalisation should be able to state these, and ideally prove them. A plausible wrong definition fails one of them.

  1. example The trivial right G-torsor G→S has neutral H¹ class, and G ×^G V is isomorphic to V.
  2. example The frame torsor of O(1) on P¹ is a G_m-torsor with line-bundle class 1 in Pic(P¹)=Z.
  3. counterexample In characteristic p, s↦s^p on G_m is a μ_p-torsor for the fppf topology and is not étale. Étale local triviality would omit this torsor.

The empty scheme with the trivial G-action satisfies E×_S G≅E×_S E (both are empty) but is not a G-torsor over a nonempty S. The definition must require E→S to be an fppf covering, i.e. to have sections fppf-locally.

What to define

Define strict normal crossings by regular local parameters whose distinct product cuts out the reduced boundary, and normal crossings by étale-local strict normal crossings. For a smooth S-family define the relative version using relative coordinate hyperplanes. A good compactification is an open immersion into a smooth proper S-family with that boundary; projectivity and existence of such a model are separate conditions.

What to define

For a Noetherian ring A: A is a G-ring if for every prime p the formal fibres of A_p → (A_p)^ are geometrically regular (a regular ring map: flat with geometrically regular fibres); A is J-2 if every finite-type A-algebra has open regular locus; A is universally catenary if every finite-type A-algebra is catenary. Quasi-excellent = G-ring + J-2; excellent = quasi-excellent + universally catenary. A locally Noetherian scheme is (quasi-)excellent if it has an open affine cover by spectra of (quasi-)excellent rings. Keep CESNAVICIUS-21's variants (CM- and (S_n)-quasi-excellence: formal fibres CM/(S_n) plus nonempty CM/(S_n) open on integral closed subschemes) as instances of the same template with the regularity condition replaced.

What to define

For a Noetherian local ring (A, m), an m-primary ideal q and a finitely generated A-module M, n ↦ ℓ_A(M/q^{n+1}M) agrees for n ≫ 0 with a polynomial of degree d = dim M. The multiplicity e(q; M) is d! times its leading coefficient, and e(M) = e(m; M). Pin the convention: IYENGAR-KHARE-MANNING-24 uses e_A(M) normalised by d = dim A, so that it vanishes when dim M < dim A; record both. For a point x of a curve, mult_x C = e(O_{C,x}).

  6. compatibility Associativity: e(q; M) = Σ_p ℓ(M_p) e(q; A/p) over primes p with dim A/p = dim M; hence e is additive on short exact sequences of modules of the same dimension (the fact IYENGAR-KHARE-MANNING-24 uses).
