## Main mathematical and prototype corrections

The following changes supplement the detailed node ledger.

- The δ(p)-unit shortcut was removed outside the p-local/Jacobson-radical setting. PD-envelope formulas now impose the Z_(p)-base hypothesis. The square-zero unbounded-torsion example has a complete mathematical regularity argument: its modules are monomial submodules of Z[f]/p^(i+1), and a uniform colon estimate ensures that f-division preserves the completion’s convergence condition. Its API now names the actual completed ring.
- Completed Hodge–Tate non-discreteness tests require nonzero completed differentials. The first conjugate-piece shifts, the perfectoid conormal line, the Nygaard step at zero and cotangent inverse-system direction were corrected. Global base-change proof sketches use the requested QCoh projection argument rather than a finite-hypercover shortcut.
- General de Rham and Frobenius-image statements retain smooth finite presentation. Lη compatibility is justified through flat differential forms and derived Nakayama, rather than unrestricted base change. The de Rham prototype was corrected to use the corresponding geometric datum.
- Perfectoid syntomic formula (9.3) is used for nonnegative twists. Negative twists use the full Nygaard step with the d^(−n) Frobenius factor. The logarithm uses q=[ε^(1/p)] and its correctly normalized θ value. The log de Rham–Witt comparison uses a filtered colimit, not an inverse limit. The abstract Artin–Schreier proof carries its sufficient ξ−p congruence explicitly.
- Cartier–Witt local principalization uses finite-projective Nakayama over the Jacobson-radical Witt kernel. The infinite kernel is not asserted nilpotent or power-adically complete. The oriented-prism cofinality argument allows changes of chosen generator; absolute conjugate descent first reduces modulo p before using its splitting.
- The q-crystalline site has the correct opposite orientation. Ten new API items give canonical unit/product, algebra coherences, functorial maps, evaluation naturality/Frobenius and a base-pair comparison map. E∞ algebra laws remain one explicit carrier contract. Framed data now require the coefficient-map, δ, complete-flat/étale-framing and smooth-quotient hypotheses from BS22 Constructions 16.19–16.20, pp.114–115. The typed prototype handles a stronger finite-presentation case; full completely ind-étale generality is an exact supplier boundary. Empty framing gives the envelope, not an arbitrary base ring.
- The AΩ subset-indexed construction supplies coordinate-injective naturality. A general ring map can identify two units, so that argument does not supply arbitrary naturality. The full theorem and its Hodge–Tate verification now have an explicit new gap asking for coherent finite indexed families or intrinsic descent. The existing multiplicativity gap is retained independently.
- PR.7’s period-ring DVR claim is restricted to O_C with C algebraically closed. Frobenius is not asserted on the B_dR completion. Breuil–Kisin evaluation is along φ∘ι_K, sending u to [π]^p. The Artin–Schreier test uses a rank-two unipotent matrix, since 1+x is not a unit in F_p[x]. The F-crystal base-change API requires the stated source/target locality-away-from-I conditions, and crystalline realization includes the qrsp comparison supplier.

Inherited quotation-style source annotations were also replaced by original-word descriptions of their mathematical/notation corrections. All these mathematical and API changes are mirrored in the reader. Every prototype section was read semantically, including PR.3, PR.4 and PR.7. Supplier adapters specify canonical constructions from their geometric parameters; no freely chosen functor, comparison isomorphism or uninterpreted proposition stands in for a theorem. Exact unavailable carriers stay in named construction-contract comments. The 26 contracts comprise 17 APIs and 9 tests; their names are enumerated in `checks.prototypeBoundary`.
