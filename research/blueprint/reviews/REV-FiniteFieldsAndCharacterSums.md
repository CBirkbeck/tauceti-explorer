### Corrected baseline entries

No declaration is removed merely because a stronger advertised statement was wrong. The following actual pinned provides contracts replace those advertisements. Audit-only near misses are explicitly marked and are not used as adapters.

- `mathlib:AddChar.map_neg_eq_conj`: For an additive character ψ on a finite additive commutative group with values in an RCLike field, ψ (−a) = conj (ψ a). The finiteness and RCLike hypotheses are essential to the pinned statement; this is not an arbitrary field-with-involution theorem.
- `mathlib:AddChar.zmodAddEquiv`: For n ≠ 0, ZMod n is additively equivalent to its group of complex additive characters. The pinned definition uses [NeZero n]; it does not state a ZMod 0 equivalence.
- `mathlib:AddChar.zmodChar`: For n ≠ 0 and a commutative monoid C, an element ζ : C with ζ^n = 1 defines the additive character a ↦ ζ^(a.val) of ZMod n. The pinned definition requires [NeZero n].
- `mathlib:AddChar.zmodChar_primitive_of_primitive_root`: For n ≠ 0 and a commutative monoid C, zmodChar n associated to a primitive n-th root of unity is primitive; the pinned theorem requires [NeZero n].
- `mathlib:AdjoinRoot.tensorAlgEquiv`: Base change over commutative rings: for p : S[X], q : (T ⊗[R] S)[X] and p.map includeRight.toRingHom = q, T ⊗[R] AdjoinRoot p ≃ₐ[T] AdjoinRoot q. The coefficient ring is T ⊗[R] S, not T; when S = R, explicitly transport coefficients along Algebra.TensorProduct.rid.
- `mathlib:FiniteField.Extension`: For a finite field k of characteristic p and n > 0 (the pinned [NeZero n] guard), a noncanonically chosen extension of degree n of k.
- `mathlib:FiniteField.algEquivExtension`: For n > 0 (the pinned [NeZero n] guard), every field extension l/k with finrank k l = n is isomorphic over k to FiniteField.Extension k p n.
- `mathlib:FiniteField.card_image_polynomial_eval`: For a polynomial p over a finite field F with 0 < p.degree, #F ≤ natDegree p · #(image of the polynomial map). The positive-degree guard excludes constants; this related bound alone does not classify permutation polynomials.
- `mathlib:GaloisField`: For prime p and n > 0, the field with p^n elements, constructed as the splitting field of X^(p^n) − X over ZMod p. The definition also permits n = 0, but its cardinality theorem requires n ≠ 0; the zero-exponent splitting field is not a one-element field.
- `mathlib:Ideal.ramificationIdx_tower`: Ramification indices multiply in towers. Requires Module.Flat S T in the ring tower, as well as r.LiesOver q. In the number-field application the finite torsion-free module over a Dedekind domain supplies flatness.
- `mathlib:Ideal.rootsOfUnityMapQuot_injective`: Reduction modulo an ideal of norm prime to n is injective on n-th roots of unity of a ring of integers. Requires NeZero n, absNorm I ≠ 1 and (absNorm I).Coprime n; do not infer injectivity for an arbitrary ideal.
- `mathlib:LinearMap.BilinForm.orthogonal`: For a bilinear form B over a commutative semiring, the right orthogonal complement of a submodule N consists of x such that B y x = 0 for every y ∈ N. Do not swap arguments without the relevant symmetry/reflexivity hypothesis.
- `mathlib:Matrix.GeneralLinearGroup`: GL n R is the unit group of the matrix semiring Matrix n n R, for a semiring R and finite decidable index type. A unit-determinant characterization additionally requires a commutative coefficient ring; the native carrier is Units, not a determinant-defined subtype.
- `mathlib:Module.finrank`: Module.finrank R M = Cardinal.toNat (Module.rank R M). It is the usual dimension for a finite-dimensional vector space; an infinite cardinal rank has toNat equal to zero.
- `mathlib:MulChar`: Multiplicative characters R → R′, vanishing on non-units. On a nontrivial domain with zero, χ(0) = 0 even for the trivial character; do not assert this without nontriviality.
- `mathlib:Nat.primeFactors`: For nonzero n, the finset of its prime divisors. Nat.primeFactors 0 is empty by convention; membership includes the n ≠ 0 guard.
- `mathlib:Polynomial.nextCoeff`: For a semiring polynomial, the second-highest coefficient when natDegree > 0; it is explicitly 0 for every constant, including a nonzero constant.
- `mathlib:UniqueFactorizationMonoid.normalizedFactors_prod_eq`: In the pinned normalized unique-factorization monoid, normalizedFactors of a multiset product of irreducibles is the multiset mapped by normalize. For monic irreducibles over a field, normalize fixes each factor; no subsingleton-unit hypothesis is required.
- `mathlib:UniqueFactorizationMonoid.normalizedFactors_prod_of_prime`: Only with [Subsingleton αˣ], normalizedFactors of a multiset product of primes is that multiset itself. This is an audit-only declaration, not the factorization-certificate adapter for general F[X], whose nontrivial constants give nontrivial units; use normalizedFactors_prod_eq and monicity instead.
- `mathlib:frobeniusNumber_pair`: The Frobenius number of {m, n} is mn − m − n for coprime natural numbers m > 1 and n > 1. A generator equal to 1 is handled separately: there are no gaps.
- `mathlib:gaussSum_one_left`: For a finite field F and an integral-domain value ring R, gaussSum 1 ψ = −1 for ψ ≠ 1. Nontriviality of ψ alone does not suffice over an arbitrary commutative ring.
- `mathlib:gaussSum_one_right`: For a finite commutative ring F and an integral-domain value ring R, gaussSum χ 1 = 0 for χ ≠ 1.
- `mathlib:jacobiSum_eq_gaussSum_mul_gaussSum_div_gaussSum`: For finite field F and field-valued characters in F′, J(χ, φ) = g(χ)g(φ)/g(χφ) when χφ ≠ 1, ψ is primitive, and the additional hypothesis (card F : F′) ≠ 0 holds.
- `mathlib:jacobiSum_mul_jacobiSum_inv`: For finite field F and field F′ with ringChar F′ ≠ ringChar F, J(χ, φ) J(χ⁻¹, φ⁻¹) = card F provided χ, φ and χφ are all nontrivial.
- `mathlib:jacobiSum_nontrivial_inv`: For finite field F and commutative-domain value ring R, J(χ, χ⁻¹) = −χ(−1) when χ ≠ 1; the ambient IsDomain R guard supplies nontrivial-character orthogonality.
- `mathlib:minpoly.irreducible`: The minimal polynomial of an integral element of an F-algebra B is irreducible when F is a field and B is a ring with IsDomain B; integrality alone in an arbitrary algebra does not suffice.
