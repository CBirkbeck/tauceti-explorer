## Corrections made

1. **PEL components and coefficients (IG.8.1, IG.10.2–3).** The definition now agrees with its own API and PELModuli M3–M4: the PEL moduli space is indexed by `ker¹(ℚ,G)` and uses the corresponding locally isomorphic inner forms. Constructors require an actual rational PEL datum, including positivity and h; the Case 2 constructor also requires anisotropy. Added extensionality. Matsushima and the Lefschetz proof sum over the PEL components; the coefficient `c(π_f)` uses the sum of their multiplicities. Replacing that sum by one component or by a factor `|ker¹|` requires an equality of component coefficients. Added a two-component acceptance check. The source uses the PEL cohomology convention in CS17 §5.1, pp. 730–731, and §5.6, pp. 749–750; the supplier states the inner-form decomposition explicitly.
2. **Integral schemes and Hecke action (IG.8.2, IG.8.4).** PELModuli M2 initially supplies a smooth algebraic space. Projective toroidal choices in ShimuraCompactifications C5, together with absence of rational cusp labels for anisotropic G, supply the scheme assertion. The Igusa action through `G(𝔸_f^p)` is only an action of `𝕋^{S∪{p}}`; added an API item and a test that excludes the spherical p-factor. The finite-level action and polynomial are unchanged in substance (CS17 §6.3, pp. 756–757).
3. **Examples and normalizations (IG.8.3, IG.8.7, IG.9.4, IG.9.6, IG.10.2, IG.11.3).** The Harris–Taylor single-nontrivial-factor test requires n ≥ 2. The repeated-eigenvalue comparison with weaker genericity now uses q = 7 and ℓ = 11, rather than implicitly assuming q ≠ 1 mod ℓ. The r-index ignores the independent GL₁ similitude character, so the rank-one r-part test and compatibility API now reflect that. Replaced an unjustified global prescribed-signature example by the local split GL₂ ordinary/basic calculation. The ordinary Newton reduction still includes its modulus twist. Restricted the rational-flag example to the split local GL₂ datum. These checks use CS17 Definition 6.2.1, pp. 755–756; §5.4, pp. 740–741; Corollary 5.5.5 and Theorem 5.5.7, pp. 746–748; and §5.6, pp. 749–750.
4. **Supplier generality (IG.9.3, IG.10.4).** ET.7b's Hecke-character-separation statement is for the noncompact rank-2n datum. Removed that direct prerequisite and gave the elementary finite-character-independence argument in the proof sketch. AG2.2's discrete unitary assembly is also stated in rank 2n, so removed it as a purported proof for arbitrary rank n. Enlarged the existing AG2.2 request to include arbitrary-rank Galois assembly, every PEL inner form, and unramifiedness at all good finite places. The narrower Harris–Taylor division trace theorem remains a comparison example, not a substitute for arbitrary-signature base change.
5. **The spectral bad set (IG.11.4–5).** After base change, the visible eigenvalues lift only the contraction to operators away from the full set `S′ = S ∪ {p,∞} ∪ Ram(ϖ)`. Corrected the minimal-stratum statement accordingly. The original final Galois proof dropped `Ram(ϖ)` when invoking the spectral export; changing p twice does not justify that omission. Added a precise finite-avoidance request to ET.0 and a gap naming the affected end theorems. The conditional proof now varies the construction for each good rational q, avoiding q in both the auxiliary prime and the character ramification, then compares constructions on their common density-one set. CS17 Lemma 5.5.1 and Corollary 5.5.5, pp. 742–746, use the enlarged bad set; Theorem 6.3.1 and its proof, pp. 757–759, assert the smaller final bad set. Shin's Lemma 7.1, p. 1722, controls allowable ramification but does not state arbitrary finite avoidance. This is a dependency gap in the blueprint, not a new source-error allegation.
6. **Localization and coefficient scope (IG.11.3, IG.11.8).** Added ClassicalAdicEtaleCohomology H0's actual filtered-colimit/cohomology statement to justify localization on the qcqs analytic flag variety. A deeper trivializing level K′ must still satisfy the constant-coefficient theorem's hypotheses: in Case 2 its bad set S′ remains contained in `Spl_{F/F⁺}`. The coefficient variant is now conditional on existence of such a level; the proof does not establish it for every algebraic ξ. The dual-ideal argument explicitly transfers genericity to the dual coefficients. Corrected the degree-zero formula to `(H⁰(S_{K′},𝔽_ℓ) ⊗ V)^{K/K′}`. The source is CS17 Remarks 1.3 and 1.7.1, pp. 651–652; this packet's coefficient statement is deliberately narrower than the unrestricted remark.
