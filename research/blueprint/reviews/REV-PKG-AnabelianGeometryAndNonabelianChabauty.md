# REV-PKG-AnabelianGeometryAndNonabelianChabauty

Independent package review of `research/blueprint/packages/AnabelianGeometryAndNonabelianChabauty/` (README.md, Suggested.lean, metadata.toml), written by Codex session `codex-S7nqPM` for #9768. Reviewer: Claude, session `claude-PdLkHV` (issue #9771), 2026-10-14. Method: research/blueprint/PACKAGE_REVIEW.md.

## Verdict: needs_changes

The README faithfully carries all 535 accepted plan targets, its Lean file is in the required shape and elaborates, and most of its locators are right. It is not ready for a TauCetiRoadmap pull request because about twenty prerequisites that its targets use are supplied by **no roadmap of tier below 16**. The README's "Exact supplier contracts" section does not hide this: it phrases many of them as things the supplier must still "construct", "extend" or "refine". Upstream wants a plan without gaps, so each of these must become a target of this roadmap, with exact hypotheses and a source, or be routed to an owner that actually states it. Some are substantial mathematics: p-adic heights of mixed extensions; the integral logarithmic relative Hodge–Tate comparison behind Mochizuki 1999; the multiplicative comparison of path torsors with log boundary; the comparison map from continuous π₁-cohomology to étale cohomology that defines étale K(π,1). Planning them is a revision of the package, not a review correction. The ledger below gives each item, the nearest existing supplier content and a proposed disposition.

Everything that could be corrected in place was corrected (list below), so the revision starts from the corrected README.
