## Repairs required by the previous review

All five previously unverifiable contracts now exercise the intended object data.

1. **CM curve.** The native fixture realizes the specified endomorphism through `A.cm`. Its opposite-normalization test conjugates the CM isomorphism on the same curve while fixing the original realization. It distinguishes the identity and conjugate characters, rather than testing a disconnected pair of scalars. The normalization test calls `etaOfOmega` and checks the cup pairing and conjugate eigenvalue. The actual geometric H¹ comparison remains an explicit CM/de Rham export.
2. **CM projector.** The rank-two tensor cube carries the actual graded S₃ permutation action. With the sign character the average has rank four; without it the average is zero. The inversion contribution is already trivial on the all-H¹ summand, and the full projector denominator is recorded. These tests distinguish Sym³ from the vanishing exterior cube.
3. **Marked isogeny.** The target CM order is literally `Z+cO_K`, and the pair uses native abelian-variety points, an isogeny and the actual kernel cardinality. Identity, composition, conductor and marked-subgroup tests use that data. Prime-to-level refers to the cyclic ideal subgroup `A[𝔑]`, rather than full `A[N]`. The characteristic-zero geometric degree/kernel comparison is a precise CM owner request.
4. **Coleman primitive.** The datum records the connection, Frobenius, annihilating polynomial, normalization complement and a witness that the input is in the connection image. The nonzero affine-disk test calls the primitive constructor on dX and excludes zero. It does not infer existence from an arbitrary module endomorphism. Analytic realization and comparison remain requested from RD.4.
5. **Universal norms.** The compact tower has commuting tame and vertical maps, closed level constraints and joint finite-height solvability. The Z/5 example has a nonzero bottom coordinate, a nonconstant trace-polynomial scalar and related coordinates in two conductor directions. Separate independently chosen norm systems would fail its compatibility tests. The compactness construction is a target with admitted proof, not an already formalized arithmetic tower.
