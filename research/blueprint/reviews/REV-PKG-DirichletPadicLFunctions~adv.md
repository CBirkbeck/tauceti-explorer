# Independent package review: DirichletPadicLFunctions

Issue #10142; job `REV-PKG-DirichletPadicLFunctions~adv`. Reviewer: Codex, session `codex-1nTmsq`, 2026-10-17. **Verdict: accepted with the corrections in this submission.** This report also records the completed-job handoff; no packet changes are proposed by this review.

## Scope and outcome

I read the six-layer package README and the complete suggested file, compared their mathematical contracts, checked the six accepted packet inputs and their package coverage index, and audited the suppliers against the current libraries and upstream roadmaps. The README remains the specification. Acceptance means that this corrected roadmap is ready for an upstream draft; it does not assert proofs of its proposed theorems.

The corrections are:

1. **GL₁ character direction (§0.5).** Distinguish a finite-unit character from the coefficient character in its Tate Euler factors. A finite-unit restriction χ gives unramified coefficient χ⁻¹(ℓ); obtaining Dirichlet coefficients χ requires finite-unit restriction χ⁻¹. A quartic character modulo 5 with χ(2)=i detects the difference, whereas a quadratic example cannot. The README and Lean now include that witness.
2. **Complex logarithm witness (§3.4).** The README's quadratic level-three computation was correct, but its Lean example dropped the outer minus sign. Its numerator is now the negative of the logarithmic difference −πi/3, giving the positive value π/(3√3). This example now has a complete algebraic proof instead of `sorry`.
3. **Weighted trivial-group quotient (§4.7).** The claimed weight-two quotient Z/3 requires multiplier set S={2}. Adding multiplier 3 gives the additional relation 8[0], so the quotient becomes zero. Both cases and the integer relation 3·3−8=1 are now recorded, with Lean examples.
4. **Native cohomology reuse (§4.12).** Remove generic Tate norm-quotient and cyclic odd-degree comparison construction obligations. Cite the current native interfaces in Scope and ownership. Retain the genuinely arithmetic targets: the point-negation action, embeddings into distribution parity quotients, their representative formulas and torsion comparisons. Rename the three comparison targets to make that distinction explicit.
5. **Eisenstein parity (§5.3).** Make even k≥4 a standing hypothesis for the actual arithmetic level-one form and every coefficient comparison in that subsection. At k=5 the Bernoulli scalar is zero while σ₄(1)=1; the README and Lean retain this negative control. Positive divisor measures in §5.1 still have arbitrary nonnegative exponents.
6. **Sources.** Correct Morita's first name to Yasuo; replace nonexistent numbered lemmas in Morita §2 by the actual section estimates and Theorem 2; correct the Robert section for the Gamma construction; correct the Morita Theorem 1 and Kubert Proposition 3.3/Lemma 3.4 page ranges.

No unresolved defect in the retained statements was found. The existing explicit limitations remain substantive: §4.14 gives exceptional-zero simplicity only under a nonzero logarithmic-projection hypothesis; §4.6 does not claim that an unweighted least-period sum is an ordinary distribution; §4.10 includes endpoint control in its smooth classification; §5.9 imposes genuine modular-form existence in exceptional low weights. These are scoped targets, not purported proofs of stronger input-packet claims. In particular, the package does not supply the extra p-adic logarithm independence needed to remove the conditional simplicity hypothesis.
