## Qualified repairs

**/1: constant families.** For `A0 × S`, the Betti differential on X has rank `2 dim(pr1 X)`. Non-degeneracy therefore means that projection to A0 is generically finite onto its image. Every subvariety is non-degenerate when S is a point; that test is false over a positive-dimensional base. Constant sections are degenerate only in the latter setting.

**/2–3, /6–9: separate prerequisites from applications.** Give the general relative Picard/Jacobian, degree-one Abel map and family difference map one early supplier, with suitable noetherian-base, smooth/projective and geometrically connected hypotheses. Put the universal level-moduli specialization downstream. Move the lightweight (Hyp) interface to the early Betti supplier or import the same shared PEL interface directly. Prefer putting the curve-family Theorem 6.2 application in the height continuation, which consumes moduli, Jacobians and general Betti non-degeneracy. The red team's merged fixes assign the difference family to three different owners; implementing all three would duplicate it and preserve the dependency problem.

Accepted RS-02 already makes AbelianSchemesAndArithmeticModuli the Jacobian challenge's Part II. Its A2 dual-Picard scope does not supply every relative-curve Picard theorem. Coordinate the new continuation as Part III. The queue code groups part-ii proposals by parent and detects only a literal `base+PartII` id; it ignores this accepted extension and does not generate the Betti alias used in the extraction. Correct the proposal ids/titles and leave a maintainer note for queue recognition/ordering. Retitling alone does not repair generated ids, and a brief does not update a queue job's `after` field.

**/4–5: mathematical statements.** Item 34 needs the intersection number of the actual represented `c1(L)`, with integration over the regular locus, not the fixed ambient multidegree. A trivial bundle/zero form disproves the existing equality. The paper expressly uses a convention in which positive includes semipositive; the word alone is not another counterexample. In David–Philippon the exponent is `(r+1) g^{5(dim X+1)^2}`: for a curve and rank zero, `g^20`. Restore the principal polarization and the published height conventions. E6's uniform-in-base-point repair remains useful, with this corrected exponent.

**/10–13, /16 and /20: suppliers must cover the consumed theorem.** Add the omitted protected Hurwitz supplier and name the actual presentation, cube-law, height, quasi-section, resolution and coarse-moduli inputs. Some are already transitively reachable; do not describe all of them as missing graph paths. Smooth de Rham–Betti comparison does not supply currents on singular analytic subsets or Lelong integrability. Split those interfaces from the SF.5/SF.6 intersection comparison, explicitly committing the analytic extension. The SeveralComplexVariablesKahlerGeometry draft is not an accepted supplier and does not presently export the whole Lelong theorem. SF.5 likewise needs an explicit widened characteristic-zero Siu nef/big commitment. Pure Shimura Ax–Schanuel and mixed Ax–Lindemann do not supply mixed universal-abelian Ax–Schanuel; the existing sibling Betti brief already requests that distinct theorem.

**/14–15, /17–18: existing and missing algebraic interfaces.** Use the pinned localization/tensor-product rank API for item 5. Finite rank is distinct from finite generation; `finrank = 0` also occurs at infinite rank. Record the single-curve Jacobian/Abel–Jacobi closed immersion with rational-base-point/base-change qualifications, importing protected Layers D/E/F. Generation can be derived from Layer F's Albanese universal property. At p.24 flatness controls Euler characteristic; vanishing, cohomology/base change and enough base twisting supply the missing fibrewise section argument. Milne supplies the required very-ample vanishing, but constant h0 alone does not prove projective normality. The counting argument also needs a positive-definite norm on each finite-rank real span: rational positivity alone is insufficient. Use a finitely generated subgroup over one number field and Northcott/coercivity to justify that stronger interface.

Correct all three Betti-torus occurrences on pp.27–28. Chevalley is already in Mathlib with finite-presentation/quasi-compact/qcqs hypotheses; the fibred-power irreducibility input needs geometrically irreducible fibres.
