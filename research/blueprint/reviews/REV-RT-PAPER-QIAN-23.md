## The findings

- **/1 (high): E43 is not propagated.** E43 corrects the signs in the proof of Lemma 4.3: π has weight +λ_τ, and the
  slope identities use τ(ϖ_v)^{+nλ_τ} and τ(ϖ_v)^{+jλ_τ}. Items 087 and 088 still state −λ_τ, −nλ_τ and −jλ_τ.
  - **Why it matters.** These items lie on the ordinary-automorphy path to Theorem 1.1.
  - **The sign check.** The norm character, with Hodge–Tate weight −1 and local value q_v⁻¹, fixes the sign.
- **/2 (high): "one m-th root" is not "all m-th roots".** p. 1268 asks for the field generated by all the m-th roots;
  items 076 and 078 ask for one m-th root of each element.
  - **The counterexample.** I checked it exactly: N = 7381 = 11²·61, l = 3, m = 7. Then k(λ) = F_{3^10}, and seventh
    powering is bijective because 7 ∤ 59048, yet μ_7 ⊄ k(λ). So 076(iv) is false.
- **/3 (high): the zero-exponent shortcut.** Remark 1.2 of the companion is not intrinsic. Translating all exponents
  leaves the H_0-character unchanged, so every character has a representative containing 0.
  - **Why it fails.** The Dwork quartic pencil, with generic Picard number 19, has non-invariant eigenpieces of rank at
    least 2 consisting of algebraic classes. Their monodromy is finite, not maximally unipotent.
  - **What I did not check.** I did not re-derive the red team's N = 5 example from A'Campo.
