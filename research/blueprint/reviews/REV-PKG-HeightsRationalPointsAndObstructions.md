| Statement | Instances tried | Result or correction |

| §0.1, Uniform boundedness at the top filter | Empty X; h(n)=(-1)^n; h(n)=n. | Empty and alternating functions are uniformly bounded, n is not. The filter is top, not eventual boundedness at a chosen arithmetic filter. |
| §0.2, Heights modulo bounded functions | On ℕ, functions 1,0 and n. | [1]=[0] but multiplying those representatives by n gives different classes. Module operations descend; pointwise multiplication/evaluation do not. |

| §0.4, Pullback of height classes | Constant map ℕ→{*}; map with empty source. | Precomposition exists without finite fibres; the contravariant composition order and empty-domain class are consistent. |
| §0.5, Surjective maps detect height classes | Identity and inclusion {0}→ℕ. | Identity detects the class; the inclusion kills [n]. Surjectivity cannot be dropped. |
| §0.6, Northcott transfer under a lower comparison | h(n)=n, g(n)=2n, and g(n)=0. | Finiteness transfers in the lower-comparison direction; reversing the comparison would wrongly make constant g Northcott. |
| §0.7, Northcott invariance under bounded error | n and n+(-1)^n; zero on infinite ℕ. | Bounded error preserves finite sublevels; constant representatives fail Northcott on an infinite set. |
| §0.8, Northcott for a boundedly equal pullback | Identity versus constant ℕ→{*}. | A pullback needs finite fibres for Northcott transfer. The constant map is a counterexample to removing that hypothesis. |

| §0.10, Polarized function fields as generalized global fields | t on ℙ¹; q/x² on ℙ² with q a conic; constants. | Orders at 0 and ∞ cancel for t; degree-weighted 2−2=0 for q/x², whereas unweighted orders give −1. Constants have height zero. |
| §0.11, The normalised projective height | [2:1] over ℚ and ℚ(i); ℙ⁰; zero tuple. | Relative heights are log 2 and 2 log 2; absolute height is unchanged. ℙ⁰ has one class, and the zero tuple is excluded. |
