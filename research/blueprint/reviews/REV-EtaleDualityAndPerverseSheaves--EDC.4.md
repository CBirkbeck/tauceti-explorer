## Mathematical corrections and counterexamples

- For smooth complete intersections, high-degree integral cohomology is free of rank one, but the hyperplane power need not generate it. A conic has h=2[point], hence h=0 modulo 2. The revised proof first proves middle torsion-freeness using saturated integral weak Lefschetz from the next smooth divisor, then uses integral duality for higher degrees. The degree-unit condition now covers both finite and integral splittings. Cross-characteristic Betti comparison stays in EDC.6, avoiding a forward dependency from EDC.4.
- The derived blow-up splitting is now constructed by the unit and exceptional-divisor Gysin maps and checked on geometric stalks. Its restriction has columns 1,−ζ,…,−ζ^(c−1). Knowing cohomology sheaves alone does not split a complex; self-intersection was added as a direct prerequisite. The self-intersection identity has no lower-power error terms.
- The t-cohomology API requires boundedness for a general t-structure. For the degenerate t-structure (0,C), every object is bounded below and all cohomology functors vanish, while nonzero objects fail the ≤0 condition. The curve constant and surface constant[1] tests have perverse degree +1. The boundary object of j!Λ[1] on a punctured line is a subobject. A point in a smooth surface disproves the recollement proof’s claimed amplitude-one bounds; the five-term sequences need only one-sided exactness.
- Deligne’s global standard-truncation formula needs the dimension-ordered filtration and an ordinary input bound. A degree-zero skyscraper inside U survives intermediate extension but is killed by τ≤−1. The generic definition still uses the image or relative glued truncation. Finite birational IC compatibility explicitly requires extension of the local system over all of the smooth source.
- ECD §27 distinguishes pullback comparison for Rf! from right-adjoint comparison for f!. The packet now proves Rc* recovery of relative duality and records strong c* duality transport as a missing input. Neither full faithfulness nor the right-adjoint RHom formula proves preservation of the essential image under diamond duality.
- BBD’s rational analytic comparison is fully faithful with a stable-lattice essential image. An analytic rank-one E local system on ℂ× with monodromy ℓ has no stable O_E lattice. Geometric cohomology finiteness cannot be applied to an arbitrary arithmetic base field. The Huber field comparison uses prime-to-char(k) torsion; it is not restricted by the residue characteristic in characteristic zero.
- Weights for affine immersions are directional: j! preserves upper bounds, j* lower bounds. Geometric Ext¹ of pure pieces can be nonzero (an elliptic curve supplies H¹); it is the Frobenius-invariant extension class that vanishes in the splitting argument. A pure unipotent Frobenius representation on a point also distinguishes arithmetic from geometric semisimplicity. Both sides of twisted relative hard Lefschetz have weight w−i.
- BBD specialization uses chosen restricted strata/coefficient categories and germs; it does not give canonical equivalences for every fibre or the entire constructible category. Its geometric-origin definition is a missing target-level object, not a lemma refinement. The categorical primitive-kernel argument cannot simply cite the vector-space graded-operator theorem. The characteristic-zero theorem’s complex coefficients and coefficient descent are distinguished.
- A finite tame automorphism is not a contracting correspondence: multiplication by −1 on the affine line demonstrates this. The proof now cites the punctured normal cone and diagonalizable-group criteria. Finally, with the packet’s definition of Δ, its square is q^(−dχ); P¹ detects the wrong sign immediately.

The vanishing-space tests now use the O(3) embedding for a plane cubic, a connected curve for the sum-map computation, and an explicit quadric threefold/surface example over 𝔽₂ where restriction and vanishing subspaces intersect nontrivially. The illustrative Springer direct sum uses characteristic-zero coefficients. A dense smooth generically finite-étale open in the small-map theorem is an explicit hypothesis.

The file’s header now reports its unaccepted status rather than claiming every simplification faithful.

Remaining signature work is concrete:

1. Encode the common finite-type separated base, invertible residue characteristic and coefficient category rather than typing geometric statements for arbitrary schemes and commutative rings. Completeness and the chosen uniformizer matter for integral categories.
2. Make IC accept an actual lisse sheaf with its dimension shift. The current arbitrary-perverse input makes dense-open independence false, for example on a skyscraper removed by shrinking the open. Add finite birational and generic-étale data where used.
3. Represent a chosen projective morphism, relatively ample line bundle, its Chern-class action and Tate twists. The current relative Lefschetz operator has no such input. A primitive part must be the specified kernel, not an existential retract (P=0 satisfies the latter).
4. State a simultaneous finite decomposition isomorphism and semisimple constituents. Purity preservation, or one retract for each degree separately, does not express those targets. The full weight filtration needs finite indexing, uniqueness and strict functoriality as well as the repaired one-step exactness.
5. Compare correspondence morphisms under canonical support isomorphisms in identity/composition/pushforward APIs. Comparing only support schemes would allow an incorrect construction with all correspondence morphisms zero. The restricted fixed-point test should compute the induced arbitrary stalk endomorphism.
6. Give local-term integration a proper structure map to the base; clopen immersion alone is insufficient. The tame-order hypothesis must concern the scheme automorphism, not merely its map on topological points. The Frobenius cohomology carrier must explicitly be geometric cohomology.
7. Add suggested examples for the two newly added packet counterexamples, strengthen the canonical homology test from zero detection to a natural identification, and replace the recollement no-adjoints smoke test. Retain the genuine shift, nodal/cuspidal, torsion/free, Kummer and !-versus-*-tests.
