## Notes on the plan, for the maintainer

None of these was changed in the package beyond what the README states; the packets are untouched.

1. **Insertion statement.** `R27.1/good-dihedral-prime-insertion` (packet R27.3) says "if moreover every prime at which ρ̄′ ramifies is smaller than p′". That never holds: ρ̄′ has weight 2 and determinant ε χ̄_{p′}, so it ramifies at p′. Khare–Wintenberger §8.4 (p. 17) take p′ larger than the primes of S ∪ {p}, S the ramified primes other than p. The README states "every prime other than p′ at which ρ̄′ ramifies"; the packet statement should be corrected in its next revision.
2. **Layer order.** `R26.6/corollary-8-1-ii-and-the-statement-W1` uses `R27.1/good-dihedral-prime-definition` and `R27.2/hypotheses-Lr-Wr-and-Dr`, while the atlas has R27.1 requiring R26.6. The README's §4 states the construction order explicitly (the three early R27.1 targets first). The proposed split of R27.1 into an early and a late part, recorded in the assembly handoff, is still the maintainer's to apply.
3. **Statement nodes before their proofs.** The R26.1 statement targets (level-one theorem, Corollary 1.2) have the R26.6 proof targets as prerequisites. The README says that their proofs are assembled in R26.6.
4. **Packet status fields.** R27.3 and R33.5 carry `status: partial` although their reviews accepted them; R26.1 carries `complete`. The package treats all three as the accepted plan.
5. **Dependencies that rest on other roadmaps' open questions**, stated in the README as dependencies, not as results: Skinner's unpublished correction for the residually dihedral ordinary case with ℚ(√p*) imaginary (the README requires it of `OrdinaryAutomorphicFormsAndModularityLifting:R21.5/nearly-ordinary-irreducible-lifting-over-q`, which at present states the theorem with that case excluded, under its own source issue); the published Duke numbering of Khare's Theorem 6.1(2) used in Corollary 1.2; and the independence audit `GL2ModularityLifting:R32.6/globalisation-dependency-audit` on which the independence of the modern route rests.
6. **Theorem 1.7's printed condition.** The R27.3 packet records as unresolved which Skinner–Wiles hypothesis Dieulefait–Pacetti's "ρ|_{D₃} ≠ identity" transcribes. `GL2ModularityLifting:R32.5/p-three-residually-reducible-branch` states it (χ̄|_{D₃} ≠ 1, automatic for χ̄₃), and the README uses that statement in R33.1 and Paso 6; the R27.3 gap can be closed by citing that node.
