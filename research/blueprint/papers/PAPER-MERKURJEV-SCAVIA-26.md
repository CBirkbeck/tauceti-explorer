## What the paper proves

For finite H, finite H-module A, and a field F containing a primitive root of order e(A)e(H), Theorem 1.3 identifies the subgroup of H²(H,A) that vanishes after pullback along **every** continuous Γ_K→H, for **every** extension K/F. It is generated by

`cor_H′^H(a cup c)`, with `H′≤H`, `a∈A^H′`, and `c∈H²(H′,Z)`.

This describes universal weak solvability of the associated abelian-kernel embedding problem. The lift need not be surjective. Galois algebras in this argument can be disconnected; replacing all of them by field extensions would lose the actual quantifiers.

Theorem 5.1 says that, for every odd prime p, n≥3 and field F of characteristic different from p, both the GL_n and upper-triangular B_n reduction extensions modulo p² are non-negligible. The theorem has **no** roots hypothesis. The proof may extend F to contain μ_p² because negligibility is monotone under base extension.

Theorem 1.4 then gives a specific field and representation: if μ_p⊂F and p is odd, `F(x₁,…,x_p)` admits a continuous n-dimensional residual representation with no modulo-p² lift, for every n≥3. The number of independent variables is p, independent of n. Chu–Kang supplies rationality of the invariant field of a faithful p-dimensional Heisenberg representation; stable rationality alone would not prove this exact statement. Padding the three-dimensional witness with a trivial summand preserves nonlifting by a pointwise block-projection argument. The same witness is upper triangular, so it also disproves the proposed flag-lifting statement, even over fields containing all roots of unity.

## Corrections that matter to the proof

**The unrestricted Lemma 4.1 fails (`/64`).** For H=C₂ acting by t↦−t on A¹_R, B=Z/2, x=(t) and f_x=t, the stabilizer is all of H. The claimed norm generator is therefore the square class of t itself. Its translate differs by the square class of −1, which is nontrivial in R(t), so it is not invariant. More generally, tensor exactness followed by invariants is only left exact; it does not establish surjectivity onto divisor invariants.

The repair needed in Theorem 1.3 is available: assume nB=0, e(H)|e and μ_ne⊂F. The stabilizer ratio h(f_x)/f_x is a character with values in μ_e, and every such value is an nth power in F×. Hence b⊗f_x is invariant under H_x, its relative norm is defined and invariant, and the orbit generators lift. This proves the restricted lemma used in the main theorem. The unrestricted printed statement remains unpromoted. The true counterexample `/64` is now owned by the cohomological Part II as a negative acceptance test. If −1=(f/g)² in R(t) with g nonzero, then f²+g² vanishes; its leading coefficient is a positive sum of real squares, a contradiction. Final-version wording still needs comparison.

Other manuscript corrections are recorded at their consuming items:

- In (2.3), the inflation target is **H²(K,A)**, not H²(L,A). The displayed segment is exact at its middle, not a short exact sequence with unnamed zero ends.

## Closing Remark 5.8(2)

This proof is supplied by the continuation, not attributed to the manuscript. Let p be odd, F contain a primitive p²-th root, A=M₃(F_p), and N={I+aE_12+bE_13 : (a,b)∈F_p²}.

For least residues a,b in {0,…,p−1}, take s(a,b)=I+aE_12+bE_13 over Z/p². All four products of E_12,E_13 vanish. Therefore, for x=(a,b), y=(c,d),

s(x)s(y)s(x+y)^−1 = I+p[κ_p(a,c)E_12+κ_p(b,d)E_13],

where κ_p(a,c)=floor((a+c)/p). Under X↦I+pX this is the restricted extension's factor set. In particular s is not asserted to be a homomorphism.

The character χ_12:N→Q/Z sends (a,b) to a/p mod Z. Its rational lift a/p has differential (a+c−((a+c) mod p))/p=κ_p(a,c). Thus its integral connecting class δχ_12 is represented by the first carry; likewise for χ_13. Since N fixes E_12 and E_13, scalar-multiplication (0,2) cups give equality already on representatives:

**res_U^N α = E_12 cup δχ_12 + E_13 cup δχ_13.**

Each summand is a generator of **barH²(N,A)** using N as a subgroup of the ambient group N. This is not the paper's φ_N with target H²(U,A): no corestriction to U occurs. Theorem 1.3 applies since e(N)=e(A)=p and μ_p²⊂F, proving negligibility.

Independently of the classification theorem, for every K/F and every continuous ρ=(χ₁,χ₂):Γ_K→N, Kummer theory lifts both characters to χ̃_i:Γ_K→Z/p². Fix ζ_p² and ζ_p=ζ_p²^p. If χ_i is represented by u_i∈K×, choose γ_i with γ_i^(p²)=u_i. The continuous character gγ_i/γ_i∈μ_p² has pth power the character from the pth root γ_i^p. Compatible cyclic identifications make it reduce to χ_i. Equality in H¹ is equality of characters because the coefficient action is trivial. Continuity follows from finite separable root extensions.

Now ρ̃(g)=I+χ̃₁(g)E_12+χ̃₂(g)E_13 has determinant one, is continuous, and is a homomorphism by square-zero multiplication. It reduces to ρ and is upper triangular. Its image need not be the full inverse-image group: this is a weak solution. No canonical choice of lifts is promised.

The finite extension over N is nonsplit by Claim 5.4, but every absolute-Galois pullback splits. This is not a contradiction. The prime-three cyclic lift over the center alone does not split N. Moreover restriction of negligible subgroups from U to N is not surjective: the nonzero T-invariant class above cannot lie in res_U^N(barH²(U,A)), whose T-invariants vanish by Claim 5.7. That is invariants of the image, so a non-invariant preimage does not evade it.

"""Exact finite regressions for the MS26 continuation; no external packages."""
from collections import Counter
from itertools import product

counts = Counter()

def check(label, condition):
    assert condition, label
    counts[label] += 1

I = (1, 0, 0, 0, 1, 0, 0, 0, 1)
O = (0,) * 9

def basis(i, j):
    return tuple(int(k == 3*i+j) for k in range(9))

def add(a, b, q):
    return tuple((x+y) % q for x, y in zip(a, b))

def scale(c, a, q):
    return tuple(c*x % q for x in a)

def mul(a, b, q):
    return tuple(sum(a[3*i+k]*b[3*k+j] for k in range(3)) % q
                 for i in range(3) for j in range(3))

def power(a, n, q):
    out = I
    for _ in range(n):
        out = mul(out, a, q)
    return out

E12, E13, E21, E31 = basis(0, 1), basis(0, 2), basis(1, 0), basis(2, 0)

def row(a, b, q):
    return add(I, add(scale(a, E12, q), scale(b, E13, q), q), q)

def adjoint_norm(x, e, p):
    out = O
    for k in range(p):
        g, gi = add(I, scale(k, e, p), p), add(I, scale(-k, e, p), p)
        out = add(out, mul(mul(g, x, p), gi, p), p)
    return out

for p in (2, 3, 5, 7, 11):
    q = p*p
    for e, f in product((E12, E13), repeat=2):
        check('square-zero row directions', mul(e, f, q) == O)
    for a, b in product(range(p), repeat=2):
        check('normalized carry', (a+0)//p == 0 and (0+a)//p == 0)
        check('integral connecting cochain', a+b-(a+b)%p == p*((a+b)//p))
        s, si = row(a, b, q), row(-a, -b, q)
        check('section inverse', mul(s, si, q) == I)
        for e in (E12, E13):
            check('N-fixed coefficient', mul(mul(s, e, q), si, q) == e)
    for a, b, c in product(range(p), repeat=3):
        check('integral carry cocycle', (a+b)//p + ((a+b)%p+c)//p
              == (b+c)//p + (a+(b+c)%p)//p)
    for a, b, c, d in product(range(p), repeat=4):
        defect = mul(mul(row(a,b,q), row(c,d,q), q),
                     row(-((a+c)%p), -((b+d)%p), q), q)
        target = row(p*((a+c)//p), p*((b+d)//p), q)
        check('section defect equals two carries', defect == target)
        check('row subgroup law', mul(row(a,b,q), row(c,d,q), q) == row(a+c,b+d,q))
    # Non-splitting of the abstract central C_(p^2) -> C_p extension:
    # every preimage of 1 has p-fold sum p, not 0 modulo p^2.
    for k in range(p):
        check('cyclic nonsplit boundary', (p*(1+p*k)) % q == p)

# Reproduce the prior checkpoint's characteristic-three linear contradiction.
s12, si12, s13, si13 = row(1,0,3), row(-1,0,3), row(0,1,3), row(0,-1,3)
for a in product(range(3), repeat=9):
    check('p3 adjoint norm', adjoint_norm(a, E12, 3) == scale(a[3], E12, 3))
    da = add(a, scale(-1, mul(mul(s13,a,3),si13,3),3),3)
    db = add(mul(mul(s12,a,3),si12,3),scale(-1,a,3),3)
    check('p3 commutator a coefficient', da[5] == a[3])
    check('p3 commutator b coefficient', db[5] == 0)

for p in (5,7,11):

check('lifted summand not preserved', add(I,scale(3,E31,9),9)[6] == 3)

    print(f'{label}: {count}')
