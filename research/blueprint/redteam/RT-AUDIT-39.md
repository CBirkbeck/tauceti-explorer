### RT-AUDIT-39/1 — high / library-claim

**Where:** research/blueprint/audit/AUDIT-39.result.json; AdicSpaces Layer 1, target 4 (zero-based), note on cΓ_v(I)

The note unconditionally characterizes cΓ_v(I) as the greatest convex subgroup for which I is cofinal. This is false in the branch where the ideal meets the characteristic subgroup. The cited greatest-subgroup theorem expressly assumes the opposite branch.

**Evidence:** Valuation.characteristicSubgroupOfIdeal, TauCeti/RingTheory/Valuation/CofinalIdeal/Greatest.lean:479, Tau Ceti f790474821cf4256814db967cb154e7af3d0c369 defines an if: when IdealMeetsCharacteristicSubgroup v I, return characteristicSubgroup v; otherwise choose the greatest subgroup. The theorem isGreatestIdealCofinal_characteristicSubgroupOfIdeal at line 495 requires (h : ¬ IdealMeetsCharacteristicSubgroup v I). IdealCofinalFor at line 103 means every element of I is cofinal. Counterexample: I = ⊤ is finitely generated, its value set contains 1 in the characteristic subgroup, so the first branch applies. But 1 belongs to I and Valuation.not_cofinalValueFor_one (CofinalIdeal/Basic.lean:251) says its value is not cofinal for ANY subgroup. Thus the family in the unconditional greatest characterization is empty. Wedhorn, Adic Spaces, arXiv:1910.05934v1, Definition 7.3, printed p.56, has exactly this case split.

**Fix:** Replace the note with both branches of Definition 7.3 and attach the non-meeting hypothesis to the greatest characterization. Add characteristicSubgroupOfIdeal_of_meets (Greatest.lean:485) for the first branch. Keep the target library tauceti and Layer 1 verdict built: the correct definition and both branch statements are present. Include I = ⊤ as a regression check against an unconditional characterization.
