# Drafts from before a split

When one job's blueprint outgrows what one review can check, `make_queue.py`
(`ONE_LAYER_PER_PART`) plans the roadmap one layer per job instead. Its packet is
split by layer into the layer jobs' packets. Its document and suggested Lean file
cover every layer at once, so they are kept here, unchanged, for the layer jobs and
the assembly job to read. Nobody edits them.

- `DirichletPadicLFunctions.md` and `DirichletPadicLFunctions.lean`: written by
  BP-DirichletPadicLFunctions (issue #713), 26 September to 2 October 2026, before
  the split into BP-DirichletPadicLFunctions--L0 to --L4.
